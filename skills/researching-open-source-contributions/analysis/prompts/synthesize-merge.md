너는 종합 결과를 합치는 조정자다. 아래는 같은 코퍼스를 나눠 종합한 그룹별 결과(후보와 `dropped`)와, 호스트가 추출 단계에서 원문과 대조한 인용 중 그 후보들이 가리키는 PR 의 인용이다. 이 입력만 근거로 쓴다. 파일을 더 찾거나 다른 자료를 쓰지 마라.

규칙:
- 여러 그룹에서 같은 행동을 가리키는 후보를 하나로 합친다. 합친 후보의 `cited_prs` 는 합쳐진 후보들이 가리킨 키의 합집합 안에서 고른다. 그룹별 `dropped` 는 참고용이다. 합친 결과의 `dropped` 에는 이번에 후보로 삼지 않은 것만 이유와 함께 적는다.
- 후보는 서로 다른 PR 2개 이상에서 **인용이 확인된**(`verified_evidence` 에 있는) 행동만 만든다. 고치거나 다시 쓰지 마라.
- `cited_prs` 는 다이제스트 키(아래 PR 색인의 `key`)만 쓴다. PR-* id 나 URL 을 쓰지 마라.
- 추출기의 confidence 는 근거가 아니다. 옮기지 마라.
- 억지로 개수를 늘리지 마라. 근거가 약한 것은 `dropped` 에 이유와 함께 넣는다. **후보가 0개여도 정상 결과다.**
- id 는 `C1`, `C2` … 순서대로 쓴다.
- 후보는 **최대 5개**, `dropped` 는 최대 20개다. 넘으면 답 전체가 거부된다(잘라내지 않는다). 5개를 넘으면 가장 근거가 강한 5개만 후보로 두고 나머지는 `dropped` 에 넣는다.

출력: 설명·코드펜스 없이 아래 형태의 JSON 객체 하나만 출력한다. 문자열 값은 한국어로 쓴다.
{
  "candidates": [
    {"id": "C1", "statement": "후보 행동을 1~2문장으로", "cited_prs": ["<키>", "<키>"], "found_by": "근거가 나온 관점·결과"}
  ],
  "dropped": [
    {"idea": "후보로 삼지 않은 것", "reason": "이유"}
  ]
}
